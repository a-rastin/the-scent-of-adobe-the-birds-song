هوای ابر را بلبل نداره

به جز شوقِ گل و سُنبل نداره

نمی‌دونه اگه بارون نباره

گُلِ پژمرده بوی گُل نداره...
\
\
\
**۱۳۸۰**

-----
-----

**English**
\
\
\
The nightingale doesn't long for the cloud;

it longs only for the rose and the hyacinth.

It doesn't know that if the rain doesn't fall,

a withered rose has no rose scent...
\
\
\
**2001–02**
