**به محمدرضا شجریان**
\
\
\
وقتی تو می‌خوانی

کسی نمی‌پرسد

برای چه می‌خوانی

برای که می‌خوانی.
\
\
\
وقتی پرنده‌ای می‌خواند

همه می‌دانند

برای چه می‌خواند

برای که می‌خواند.
\
\
\
وقتی من نقاشی می‌کنم

تو می‌پرسی

برای چه؟...

برای که؟...
\
\
\
**پاییز ۱۳۶۸**

-----
-----

**English**
\
\
\
**To Mohammad-Reza Shajarian**
\
\
\
When you sing

no one asks

why you sing,

for whom you sing.
\
\
\
When a bird sings

everyone knows

why it sings,

for whom it sings.
\
\
\
When I paint

you ask:

why?...

for whom?...
\
\
\
**Autumn 1989**
\
\
\
**Notes:**
- Mohammad-Reza Shajarian (1940–2020) was the greatest master of Persian classical singing.
- `Mikhānad` means both "sings" and "reads or recites." Here it's clearly "sings."
