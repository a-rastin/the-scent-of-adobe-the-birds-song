هر نَفَسی که پرنده می‌خواند...

یک نفس...

به وصل... نزدیک تر می‌شود...
\
\
\
**دههٔ ۱۳۸۰**

-----
-----

**English**
\
\
\
With every breath the bird sings...

one breath...

closer... it comes to union...
\
\
\
**The 2000s**
\
\
\
**Notes:**
- `Nafas` (breath) carries the poem. Each sung breath brings the bird one breath closer to union, so singing is itself the way toward the beloved.
