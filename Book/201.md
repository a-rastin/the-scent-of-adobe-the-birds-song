ماه روشن بود... و...

مهتاب آبی...

آنشب...

همایشی در ستایشِ بوسه داشتیم...
\
\
\
**دههٔ ۱۳۸۰**

-----
-----

**English**
\
\
\
The moon was bright... and...

the moonlight blue...

That night...

we held a conference in praise of the kiss...
\
\
\
**The 2000s**
\
\
\
**Notes:**
- `Hamāyesh` is a formal word for a conference or symposium, so using it for a night of kisses is playful. It's a solemn "gathering in praise of the kiss."
