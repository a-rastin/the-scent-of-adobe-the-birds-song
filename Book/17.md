**زندگی...**
\
\
\
یک نوا،

یک ترانه،

یک آواز،

یک نگه،

یک تبسم و

یک ناز،

دو کبوتر دو روز در بَرِ هم

روزِ سوم اسیرِ پنجهٔ باز.
\
\
\
**کوی دانشگاه، تهران ۱۳۴۲**

-----
-----

**English**
\
\
\
**Life...**
\
\
\
One melody,

one song,

one voice,

one glance,

one smile and

one coy charm,

two doves, two days in each other's arms,

on the third day, prey in the falcon's claws.
\
\
\
**Kuy-e Daneshgah, Tehran, 1963**
\
\
\
**Notes:**
- `Nāz` is the playful, flirtatious coyness of a beloved. English has no single word for it, so I used "coy charm."
