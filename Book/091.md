یک مرد،

یک سنگ،

و تنهٔ پیر یک درخت

و در زمینه،

مِهی غلیظ...

یک خطِ کوتاهِ آبی...

یک نقطهٔ کوچکِ سرخ.
\
\
\
ای کاش خاطره...

مثلِ ابر می‌بارید...

مثلِ خورشید می‌تابید...

و چون غبار...

گم نمی‌شد...
\
\
\
**دههٔ ۱۳۷۰**

-----
-----

**English**
\
\
\
A man,

a stone,

and the old trunk of a tree,

and in the background,

a thick fog...

one short blue line...

one small red dot.
\
\
\
If only memory...

rained like a cloud...

shone like the sun...

and didn't vanish...

like dust...
\
\
\
**1990s**
