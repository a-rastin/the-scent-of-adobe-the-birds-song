نشانی شوق را...

از نگاهِ من بپرس...

هر روز... پیش از آن که...

در آینهٔ اتفاق ببینی...
\
\
\
**۱۳۸۴/۴**

-----
-----

**English**
\
\
\
Ask my gaze...

for the address of longing...

every day... before

you see it in the mirror of chance...
\
\
\
**July 2005**
\
\
\
**Notes:**
- `Neshāni` means both "address" and "sign," so the line asks where longing lives and how to recognise it.
